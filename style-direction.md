# Design DNA — Editorial
**Philosophy:** Stories before interfaces.
**Overall feeling:** Calm, premium, thoughtful — a magazine feature, not a dashboard.

## Direction
Build this portfolio to feel Calm, premium, thoughtful — a magazine feature, not a dashboard. Follow every value below exactly.

## Specification
- Typography: Elegant Serif          (attendee knob)
- Motion: Smooth                  (attendee knob)
- Spacing: Balanced                (attendee knob)
- Layout: Asymmetric magazine grid, wide margins
- Color: Warm neutral + one muted ink accent
- Corner radius: Medium-soft
- Image treatment: Large, rounded, high-contrast
- Cards: Borderless — separated by space
- Shadows: Soft, diffuse
- Hero: Split editorial — oversized headline + portrait
- Navigation: Minimal floating top bar
- Background: Warm off-white gradient (light mode)

## Never
Dense dashboards, heavy gradients, fast/flashy motion, tiny type, card overload.

## Placeholder styling
Soft rounded blocks in warm neutral tones — intentional editorial slots.
