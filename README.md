# Your PortfolioKit
Everything Cursor needs to build your live portfolio.

## The 4 steps
1. Open this folder in Cursor.
2. Open prompts.md, copy Prompt 01, paste it into Cursor.
3. Push to a GitHub repo and enable GitHub Pages.
4. Open your live URL. 🎉  (Custom domain optional.)

## Inside
- cursor-context.md, about.md, case-study.md … case-study-3.md, style-direction.md, prompts.md
- assets/images — your uploaded screens and/or placeholders
