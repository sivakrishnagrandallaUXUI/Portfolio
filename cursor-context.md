# Portfolio Build Brief

You are building a single-page personal portfolio website for a designer.
Read every file in this kit before generating anything.

## Source of truth
- about.md — who they are, bio, skills, contact
- case-study.md … case-study-3.md (3 case studies) — their work. Some may be
  self-initiated redesigns or anonymized NDA work — respect those labels as written.
- style-direction.md — the Design DNA. FOLLOW IT EXACTLY, including any
  "Designer's notes". Honour real images in assets/images/; keep placeholders where present.

## Hard requirements
1. Single-page, responsive, mobile-first. Show all case studies.
2. Obey style-direction.md — no generic defaults.
3. Use provided images; keep placeholder images and TODO comments where no image exists.
4. Accessible, semantic, keyboard-navigable. Deployable to GitHub Pages.
5. Clean, commented, editable code.

## Do NOT
- Invent facts. Override the Design DNA. Remove TODO placeholders. Reveal anonymized NDA client names.
